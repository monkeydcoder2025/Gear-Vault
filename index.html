Connect to Firebase so all your friends can access the same inventory in real-time.

1

Create a Firebase Project

Go to Firebase Console → Click "Add Project" → Give it a name → Continue

2

Add a Web App

In your project, click the Web icon (</>) → Register app → Copy the firebaseConfig object

3

Enable Realtime Database

Go to Build → Realtime Database → Create Database → Choose region → Start in test mode

4

Paste Your Config Below

Paste the firebaseConfig JSON object from Step 2
